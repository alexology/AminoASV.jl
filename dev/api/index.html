API

AASV.AASV — Module
AASV

Functional analysis of COI ASVs, a Julia implementation of the R pipeline aasv: reference profiles per species, genus and family (align_species_seq!, align_genus_seq!, align_family_seq!), their curation (improve_alignment!, filter_divergent_seq!), the structural (hydrophobicity) and mutation audit of each ASV (assess_asv, asv_functional_structure!) and the final classification (classify_asv). Sequences and alignments are shared with ProfileAlignments.jl.

AASV.align_family_seq! — Function

Merge genus profiles into family FASTA alignments, largest profile first. show_progress=true reports families, taxa and each profile merge. After merging, records whose insertions open gap columns in most references are removed iteratively (remove_gap_causing=true; R aasv relies on check_alignment and improve_alignment at each level), and listed in log_dir/gap_causing_references/<level>/<family>/<taxon>.tsv (log_dir=nothing disables the report). Otherwise a few such records make every query an indel at that level. Existing profiles are reused unless overwrite=true.

AASV.align_species_seq! — Function

Download, filter, translate and align species references for all input families. records_provider(family) may supply local BOLD-like records (processid, identification, sequence). Outputs follow the original R directory layout. show_progress=true reports families, downloads, filtering and each species before alignment. Filtering updates use progress_interval seconds (default 5). Complete BOLD pages are cached under alignment_dir/bold_downloads/<family>. With overwrite=false, interrupted downloads resume from that cache, also in a new Julia session; overwrite=true starts a fresh query and download. New species outputs are prepared before installation; obsolete species files, derived genus/family profiles and their curation checkpoints are removed after a successful build. Other families and files outside the managed formats are preserved.

Reference checks

AASV.check_alignments! — Function

Check all reference families and return problematic FASTA paths, including cached results. Checkpoints in alignment_dir/checkpoints/check_alignment are reused only when file names, SHA-256 contents, rank, type and algorithm version match. Set resume=false to repeat checks. Missing/empty rank directories are skipped.

source
AASV.check_reference_records — Function

Report reference records that asv_functional_structure! ignores or excludes. Returns a table with family, tax_lev, file, record and issue: "repeated" (exact repeat of a record), "conflicting" (ID repeated with another sequence; analyses stop on it) or "no_nucleotide_reference" (profile record without a nucleotide reference in the taxon, such as another genus in a genus profile or an altered ID written by an earlier aasv version). Genus and family profiles can be rebuilt with overwrite=true. Realigning species files from the raw sequences would restore records removed by earlier curation; rebuild them with align_species_seq!(overwrite=true) instead.

source
AASV.filter_divergent_references! — Function

Filter all reference families with persistent SHA-256 checkpoints. Returns the current FASTA paths. resume=true reuses completed families only when their output files, max_distance, min_seqs and algorithm version match. Each family's removal report is retained in its checkpoint and written to log_dir/divergent_references/<rank>/<family>.tsv. Filtering operates on the current files; changing thresholds cannot restore previously removed records. Prepared outputs allow interrupted installation to resume without filtering twice.

Alignment and curation

AASV.align_profiles — Function

Align existing profiles through the standalone Julia ProfileAlignments engine. Defaults: BLOSUM62, affine gapopen=-10/gapextend=-1, free terminal gaps. mode=:query fits the first profile into the second. FFT anchors are optional. Legacy gap selects a linear penalty; match/mismatch select scalar scores.

AASV.filter_divergent_seq! — Function

Remove singleton outliers using nearest-neighbour uncorrected amino-acid distance. Terminal gaps are excluded; if every sequence is flagged, the file is retained. Identical sequences share comparisons; duplicates with nongap residues have distance zero. Distances remain exact, including those written to removal logs. show_progress reports file counts and pairwise comparisons every progress_interval seconds (default 5), plus start/completion messages. It defaults to print_messages, but can be enabled independently.

AASV.improve_alignment! — Function

Remove gap-causing representatives first, then internally gapped ones. Duplicates are restored. If all candidates are flagged, a sibling species reference breaks the tie; without one, retain the first candidate deterministically.

AASV.re_align! — Function

Realign FASTA alignments in place, without their gaps. With raw_sequences=true, species alignments are rebuilt from raw_sequences, as in R aasv: this resets the curation, restoring records removed by improve_alignment! or filter_divergent_seq!. To rebuild species references, use align_species_seq!(overwrite=true).

AASV.assess_asv — Function

Audit a query against an amino-acid reference profile; report novel residues, codon coordinates, Grantham distances, ORF incompatibilities and hydrophobicity. Optional VSEARCH mapping uses Phred+33 error probabilities for read-back quality, from the FASTQ files of asv_samples. sample_names lists every sample of the study, so that a file matching several names is rejected (default asv_samples).

Classification

AASV.ClassificationConfig — Type

Configuration for the Functionality Index calculation. Pass this value positionally to classify_asv when the same policy is reused.

source
AASV.classify_asv — Function

Compute the R package's COI Functionality Index from Excel or TSV reports. FI = 1 - (0.35 × mean site penalty + 0.30 × codon penalty + 0.35 × hydro). Hard ORF incompatibilities (aa_pos=-1) force FI=0. Low-quality mutations are excluded; missing quality is accepted. This score measures compatibility with functional COI evolution and does not establish mitochondrial/NUMT origin.

Shared with ProfileAlignments.jl

Sequences, alignments and FASTA files are those of ProfileAlignments.jl, re-exported by AASV, so using AASV is enough:

  • Alignment(records; weights): rectangular alignment of Sequence records, with names, order and normalized positive sequence weights.
  • read_fasta(path): read a FASTA file (FASTX.jl) keeping full headers, record order and gap columns; malformed files raise an ArgumentError.
  • write_fasta(records_or_alignment, path; width = 80): write Sequence records or an Alignment; empty sequences are rejected before the file is created or truncated.
AASV.Sequence — Type
Sequence(id, sequence)

Named sequence, normalized to uppercase ASCII; alignment gaps use -. The sequence and FASTA API (Sequence, Alignment, read_fasta, write_fasta) is shared with ProfileAlignments.jl (ProfileAlignments.Sequence).
